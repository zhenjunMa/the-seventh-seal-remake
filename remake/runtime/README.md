# 第七封印 · 运行与操作

启动和素材前置见[项目说明](../../README.md)；当前接入范围与验收状态只在[开发计划](../assessment/validation_design.md)维护。本文说明现有操作。

## 启动和主菜单

从仓库根执行：

```console
python3 -B remake/runtime/serve.py
```

Windows使用Python 3的python命令，或双击remake/start.cmd／start_runtime.cmd。访问<http://127.0.0.1:8767/>，启动窗口保持运行；服务代码更新需重启，普通前端／配置修改刷新页面即可。

旧媒体迁移见[旧环境升级](tools/README.md#旧环境升级)。无媒体可访问`/phaser-preview.html`体验示意场景，该页面不读写正式存档。实验目录另由prototype服务运行。

片头按原顺序播放，Esc可跳过；等待页按键／点击进主菜单。左右选择读取／游戏／特典／离开，Enter或空格确认，Esc逐层返回。游戏按640×480等比显示，首次交互前媒体可能受浏览器自动播放限制。

“开始游戏”进入真实新游戏；读取仅处理重制存档。探索中返回标题后可“回到游戏”；音乐欣赏提供已接入曲目。终章提交后返回标题并禁止继续探索，仍可读取此前存档；不自动存档或开放完整特典界面。

## 探索和剧情

| 操作 | 按键／行为 |
| --- | --- |
| 移动／跑步 | 点击地图聚焦，WASD或方向键，Shift跑步；斜走不额外加速 |
| 交互 | 靠近NPC、箱子、床或通讯水晶后按E |
| 对白／选择 | Enter、空格或点击；文字未完先补全，问题选项显示后方向键选并确认，选项无Esc取消 |
| 大地图 | 方向键循环已解锁地点，确认或点击前往，Esc回当前场景 |
| 快速存取 | F4保存、F5读取；标题也可F5读快速档，长按只执行一次 |

人物步态按实际移动距离推进；完全受阻但仍输入时慢速踏步并有短暂身体反馈，松键待机。该反馈不改变世界坐标、阴影、出口或遇敌。普通NPC平滑显示并与玩家双向阻挡，被挡后保留路径，让开继续。

现有新游戏由神殿序章进入火之谷，邀请凯并领取装备后离谷；后续区域可经大地图、外层白木森林、翠碧湖到炎城，具体自然路线与分段交接的验收边界见计划。地图资源存在不代表所有原时期入口均开放；重访沿原旗标，不按进出次数推进。

元素箱需对应钥匙，钥匙不消耗，动画与奖励成功后保存完成状态；背包满时保持未开，可腾位后重试。剧情赠物仍需手动装备。已接入城镇服务沿原NPC入口打开买卖、住宿或制作，实际开放分支取决于来源与登记。

演出中限制保存、换人和启动其他流程；未知分支会明确拒绝。剧情提交、地图切换或存取失败时保留可恢复进度。

## 操作菜单

Tab或侧栏打开菜单，方向键切换，Enter／空格确认，Esc逐层返回。只显示实际加入队伍，登记角色不会自动入队。

| 页面 | 操作与规则 |
| --- | --- |
| 状态／装备 | 选人物、部位与候选装卸；左右切属性预览，灰色表示不合资格，尾行卸下 |
| 道具 | 已接入药品可按实际资格场外／战内使用；目录不保证所有效果可执行 |
| 队列 | 四个固定位置，选择人物或空位后确认交换；地图领队与战斗阵位分别保存 |
| 技巧 | 使用／编成／测试三页，七槽绑定，组合创建／改名／删除；PageUp／Down翻页，X／Z按页面提示切人物／分类 |
| 命名 | Esc在字符区和操作区切换，取消按钮丢弃草稿 |
| 技巧测试 | 进入原TestStage并返回同页；保留MP资格，不扣施法MP／受击HP，药品等实际资源变化仍按规则提交 |
| 法器 | 选孔和晶石镶嵌，尾行卸下；替换先返还，换武器保留人物六槽，当前武器决定可操作孔数 |
| 系统 | 总音量、音乐、音效、静音、初始／记忆光标及返回标题；偏好独立于世界存档 |

特殊药品、晶石和被动只按已恢复范围可用。例如回转之钥为免疫而非自动复活；未恢复效果不会因道具在包中自动生效。

## 战斗

野外按地图原已接入概率和敌群表产生遭遇，资源准备保留地图画面，再衔接转场和人物入场。每名参战者独立充槽，选命令及动作期间仍推进规则时间。

满槽用方向键选七槽命令，Enter／空格确认，Esc逐层返回。轮盘Esc进人物选择，按原阵位选队员并重开轮盘；也可点人物条或用Tab／X／Z切满槽人物。每名符合资格的队员可分别确认一条待执行指令，道具数量保留至使用或取消。

“使用招式”首次默认编成技巧；点击顶部图标或左右切编成／魔法／一般／特殊，上下选条目，首行按上回分类。记忆光标保留当前人物分类及条目，初始光标每次回编成。组合按保存顺序调用各成员技能，未接入或不合资格的组合明确禁用。

目标资格沿原规则，例如燕突不能攻击飞行角鹰，雪泥部分姿态避开物理攻击。全队倒下完成败北流程回标题，不发胜利奖励；普通逃跑按人物处理，其他仍在场队员继续战斗。

胜利确认完成后一次提交HP／MP、物品、经验、成长和掉落，重复返回不重复发奖。特殊状态与表现的剩余边界见计划。

## 保存和兼容

通讯水晶附近按E，选“使用。”进存档页；选择00～19，确认储存，已有文件再确认覆盖。Esc先取消覆盖再退出，不写文件；侧栏普通存档／读取同样打开栏位页。

| 项目 | 行为 |
| --- | --- |
| 普通档 | `remake/saves/SaveGame00.json`～`SaveGame19.json` |
| 快速档 | 独立`QuickSave.json`，F4写、F5读 |
| 栏位导航 | 三行显示；方向键／滚轮逐项，PageUp／Down翻三项，Home／End首末 |
| 保存时机 | 探索可存，剧情／战斗／菜单／加载限制保存；读取仅在探索／标题允许 |
| 失败保护 | 存取锁输入，写盘成功才提示；错误保留原文件及当前进度 |
| 旧单档 | 无00文件时读旧SaveGame0.json，旧文件保留，新存写00 |
| 旧浏览器档 | 仅迁入空00且保留浏览器副本，已有文件档优先 |

存档由本地服务写盘，换浏览器或端口仍读取同目录；不直接兼容原版.Dat／Game.SAV。新档附带校验绑定的缩略图，旧档预览只读重建。

等级、资源、背包、队列、技巧、晶石、学习与当前地图NPC状态随世界保存，配置独立。调参前保存，修改后刷新再读取；原实例不会因改参数重新抽取。

## 开发样本

“开发检查→三人扩展样本”使用独立世界加入凯与娃蒂，英格妮沿原成长到12级并显式授予燕落，娃蒂沿原25级，位于森林。样本走正常遇敌事务，不改变正式主线的学习／获取条件。

“99级全技能测试A／B”均六人99级、四人出战、两人候补；A为001／002／003／004，B为001／004／005／006。准备只写样本学习进度，不自动保存。原条件表、导入JSON及后期阶段档按[本地资料](../local_materials.md)交接；历史12级路线和一对一入口保留原限定范围。

主动保存或导入仍经过正式入口。样本及来源交接档不代表自然入队、取得钥匙或完成全主线。
