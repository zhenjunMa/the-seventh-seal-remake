# 第七封印 · 运行与操作

更新：2026-10-28

本文描述当前代码支持的操作；本版验收状态与待办见[validation_design.md](../assessment/validation_design.md)，素材前置条件见[README.md](../../README.md)。

## 启动和主菜单

Windows 可在 `remake` 目录双击 `start.cmd` 或 `start_runtime.cmd`，也可从仓库根目录执行：

```console
python -B remake/runtime/serve.py
```

macOS/Linux 从仓库根目录执行：

```console
python3 -B remake/runtime/serve.py
```

所选命令需指向 Python 3。

浏览器访问<http://127.0.0.1:8767/>，已有服务时刷新即可。启动窗口需要保持运行。

旧环境仍将素材放在`remake/prototype/web/assets`时，启动前按[README.md](tools/README.md)的“旧环境升级”复制至正式素材目录；媒体和来源资料的交接范围见[local_materials.md](../local_materials.md)。更新服务代码后需重启服务。

正式服务只提供本目录的web。旧地图／战斗实验由prototype服务单独启动，操作见[README.md](../prototype/README.md)；无素材预览仍在正式服务的`/phaser-preview.html`。

游戏使用随代码提供的Phaser `3.90.0`；素材需另外准备。替换`serve.py`后应重启服务；加载、场景与暂停机制见[architecture.md](architecture.md)。

片头按原顺序播放，Esc可跳过；等待页按键或点击进入主菜单。左右选择读取／游戏／特典／离开，空格或Enter确认，Esc逐层返回。界面按640×480整体等比显示。

游戏→开始游戏进入真实新游戏。读取只读取重制存档；音乐欣赏提供已接入的原曲列表。探索中返回主菜单后可“回到游戏”继续当前进度。

媒体播放遵守现有音量／静音设置，浏览器首次交互前可能静音自动播放。

## 探索和剧情

点击地图获得焦点；WASD／方向键移动，Shift跑步，E交互。Enter／空格或点击推进对白；文字未完时先补全，满行后滚动或换页。

玩家走路／跑步节奏随实际移动距离推进；贴墙受阻、松键和切换界面时停止移动动作，斜走不额外加速。剧情人物与普通NPC也按移动距离推进脚步，普通NPC平滑显示；人物和脚下阴影同步移动。

F4快速存档，F5快速读档；在主菜单也可按F5读取快速档。按键长按只执行一次，F5不会触发浏览器刷新。

问题文字完成后显示选项；方向键选择，Enter／空格或点击确认。按住确认只处理一次；选项没有Esc取消。

当前代码接入的正式路线：神殿序章→村庄西南王厅邀请凯→村庄东北住处领取装备／与长老交谈→村庄南口→火之谷南出口→大地图→白木森林→翠碧湖→炎城运炎河右岸交接。各段当次实玩状态仍以开发计划为准。

火之谷21张原地图与147个NPC实例已导出，63个有原对白入口的NPC均已登记；沿原物理出口探索支路。重访按原剧情旗标改变站位、显隐和对白，读档不会重播到达事件。三个祭坛变体、区域外NPC回谷交接、后期演出及stage12剧情战已连接；阶段入口取决于其他区域推进的真实旗标，不能连续进出就触发。具体当次验收范围见当前开发计划，来源与阶段合同见[story_guide.md](story_guide.md)。

装备箱按剧情条件发放珍珠耳环、烈焰冠和兽骨戒指；长老另赠茶。已领取事件不重复发放，装备需要在菜单手动穿戴。

外层白木森林M70010／20／30／40／50／60六图按原出口连接，13个元素箱在附近按E查看；需要持有对应元素钥匙，钥匙不消耗，开启动画完成后提交原奖励。背包满时保持未开，腾出空间后重试。伊斯坦按外区委托旗标出现，赠礼与追击营地按原旗标变化；本轮不含里白木森林及完整外区任务路线。

翠碧湖首次通行由森林出口的大地图进入湖入口，经湖岸与三段湖上到对岸，再从原大地图前往炎城运炎河右岸。湖入口与炎城右岸的通讯水晶可保存；右岸原出口可返回大地图。雷兽、刽齿蛟沿原stage07与敌群表遇敌。后续融湖仍由原剧情旗标改变通路，不能靠重复进出触发；后期元素箱、小吉救援及炎城城内流程按后续阶段接入。

住处床附近E可选择休息／不用。未邀请凯、未领取装备等出口条件沿原已接入剧情判断。

大地图方向键循环选择已解锁地点，Enter／空格或直接点击前往，Esc回当前场景。资源已提取的地点仍可能尚未开放剧情。

演出过程中限制保存、切换人物和启动其他流程；遇到尚未恢复的剧情分支会明确提示。

终章依原演出播放片尾、等待并提交后返回标题，不能继续探索，不自动写游戏存档。独立通关标记保存在本浏览器；仍可从标题读取此前存档或开始新游戏，完整特典界面不由此自动开放。

## 操作菜单

Tab或侧栏入口打开菜单。方向键切换，空格／Enter确认；Esc从详情逐层退回。菜单显示已加入的队伍，不因登记角色而自动入队。

- **状态与装备**：选择人物、部位和物品装上／卸下，灰色候选表示不合资格。装备页左右切换属性预览，候选可滚动，末尾空行用于卸下。

- **道具**：支持已接入药品的场外使用与战内目标选择；目录展示不等于该道具作用已实现。

- **队列**：四个固定位置，选择人物或空位，再次确认交换；地图领队与战斗位置分开保存。菜单、状态和装备页的待机速度由同一角色战斗idle来源生成。

- **技巧**：使用／编成／测试三页，支持七槽命令绑定、组合记录创建／改名／删除。PageUp／PageDown翻页，X／Z切分类或人物（以当前页面提示为准）。命名Esc在字符区和操作区切换，取消按钮丢弃草稿。

- 技巧测试进入原TestStage，退出返回同一技巧页。测试保留MP资格判断，不扣施法MP、不扣受击HP；药品消耗和恢复等资源变化仍按已接入规则处理并提交。

- **法器**：选择孔位镶嵌已接入晶石，空白尾行卸下。替换先返还旧晶石，换武器保留人物持有的六槽记录。紫龙晶已接入原混乱免疫初始化判定；回转之钥可作为宝器装卸，其原效果为免疫而非自动复活。其他特殊被动按能力登记限制。

- **系统**：总音量／音乐／音效、静音、初始／记忆光标及返回主菜单。声音偏好与世界存档分别保存。

## 战斗

野外行走按各地图原已接入概率与敌群表生成1～4敌组。每位参战者独立充槽，选择命令和播放动作期间仍推进计时。

遇敌后直接衔接入战转场与人物入场，不插入载入画面；资源准备期间保留地图画面。

满槽时方向键选择七槽命令，空格／Enter确认，Esc逐层取消；在轮盘按Esc进入人物选择，方向键按原阵位选择队员，空格／Enter重开轮盘。也可点击人物条或用Tab／X／Z切换满槽人物。动作期间每名符合资格的队员均可分别确认一条指令，由原充能／阵营规则依次执行；已确认的道具数量会保留至使用或取消。

使用招式和物品读取菜单保存的绑定。编成技巧可从绑定轮盘或“使用招式”列表选择，按保存顺序合并各招动作，并分别使用成员招式的配置、消耗和熟练度；包含尚未接入的招式时提示原因并禁用。防御、逃跑、目标死亡后重选、无效药品目标取消沿已接入规则处理。

燕突不能攻击飞行角鹰；雪泥的命中方位随完整待机动作切换，部分姿态会避开物理招式，其他姿态可被命中。已学会且满足MP条件的法术沿原特效路径结算。

一人倒下时其他人继续行动；全队倒下播放败北电影并回主菜单，不发胜利奖励或自动复活。普通逃跑按人物处理，仍在场的队友继续战斗。

结算通过原报告／通知流程展示，确认完成后一次提交HP／MP、物品、经验、成长、掉落与奖励去重记录。存活且符合资格的参战者各获完整经验池。

部分特殊状态／技能及精确动态镜头仍有边界，详见唯一当前计划。

## 保存和兼容

通讯水晶附近按E，选择原始“使用。”进入原版素材的存档页面；选择00–19栏位，Enter／空格或顶部“储存”确认。已有存档需再次确认“覆盖存档”；Esc先取消覆盖，再退出页面，不写文件。侧栏普通存档／读取也打开栏位选择页。

普通档分别写入`remake/saves/SaveGame00.json`至`SaveGame19.json`；F4写入独立的`QuickSave.json`，F5读取该快速档。栏位一次显示三行，方向键／滚轮逐项选择，PageUp／PageDown翻三项，Home／End到首末项。主菜单读取页同样支持滚动选择全部已有档位和快速档。

存档由`start.cmd`启动的本地服务写入磁盘；重启服务、换浏览器或端口仍读取同一`remake/saves`目录。首次保存会自动创建目录，更新`serve.py`后需关闭旧服务并重新启动。

旧`SaveGame0.json`在00文件缺失时作为00号档读取并保留原文件；新保存写入`SaveGame00.json`。旧浏览器存档仅向空00号档迁移并保留浏览器副本，已有文件档优先。导入／导出仍为重制JSON，不写原版.Dat或`Game.SAV`，也不直接兼容原版二进制存档。

地图探索时可保存；剧情、战斗、菜单和加载期间限制保存，读档仅在探索／主菜单允许。存取期间锁定输入；文件写入成功后才提示已保存，异常保留原文件／当前进度。

存档保留世界进度、资源、队列、技巧绑定／组合、晶石和已接入技能学习／熟练度状态；配置数值独立于存档。

六名队友的154条命名技能已接入。进入地图后，可在“开发检查”选择“99级全技能测试 A组／B组”：A组为英格妮、凯、娃蒂、佛兰珂；B组为英格妮、佛兰珂、朱特、赛拉飞尔。两份样本均保存六人99级和全部技能学习状态，四人出战、两人候补，不自动写入玩家存档。可导入JSON和原学习条件清单见[A组测试文档](evidence/party_skill_alignment_20261027/test_a_99.md)与[B组测试文档](evidence/party_skill_alignment_20261027/test_b_99.md)；正式新游戏仍保留原等级和学习条件。

调试修改技能、道具等配置后，先保存并刷新游戏页面，再读档继续；配置在页面启动时加载，返回标题或开始新游戏不会重新加载，无需重启本地服务。

新保存附带校验绑定的场景缩略图；旧重制存档没有截图时只读重建预览，不重写旧进度。

开发样本不会自动保存，主动保存或导入仍会经过正常操作入口。

## 开发样本

开发检查→进入三人扩展样本：使用独立新游戏来源加入凯与娃蒂，英格妮按原成长升至12级并显式测试授予燕落，娃蒂保持原25级，位于白木森林。

样本预置可重复的遇敌检查点，走一步进入正常遇敌事务；正式遇敌算法和主线旗标没有被样本替换。

历史12级路线、一对一战斗等入口各有原限定范围，不作为新增主线已贯通的证据。

014保留工具隔离导出的限定范围；火之谷已开放内容及当次验收范围见当前计划。后期阶段开发存档的来源和限制见`evidence/fire_valley_20261025/phase_fixture_manifest.json`，不作为原版存档或完整主线通关记录。

外层白木森林普通、伊斯坦委托、追击与追击后交接档见`evidence/white_forest_20261026/phase_fixture_manifest.json`；钥匙测试位置与物品准备另见`chest_browser_fixture_manifest.json`。它们通过正式导入入口使用，不能当作自然取得外区钥匙或完成外区主线的证明。
